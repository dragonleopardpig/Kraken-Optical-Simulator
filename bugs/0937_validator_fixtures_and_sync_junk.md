# 0937 -- validator fixtures kept in git; generated folders kept out of Filen

User request (2026-10-01): "there are some unnecessary directories generated by you which shouldn't
even go to filen synchronization, for example, __pycache__ ... identify all and deal with the issue";
then "any files related to your guard, validation, test, that must not be deleted, can you put them
all in a specific folder and git it?" Scope chosen: the project's OWN scenes only (the repo is
public; no vendor CAD).

## What was going wrong

**Filen's `attachment/` sync had been STALLED since at least 2026-09-29, and also on 09-23.**
- Phase 500's guard (0667) created `attachment/cells/_guard_0667/`. Production
  `open_station_for_face` writes a new station into `attachment/cells/<scene>/`, and the guard
  deleted the folder again when done.
- Filen queued the folder for upload. It vanished (ENOENT), and @filen/sync then logged "Not
  continueing sync cycle, got taskErrors" every 5 s and synced nothing more in that root.
- No `.filenignore` existed in any sync root on X299-SSD, although July's notes recorded one.

## Fixed

- **`attachment/.filenignore`** (Filen runtime config, not in git) now excludes:
  - `__pycache__/` and `*.pyc` (Python writes these beside every layout it imports);
  - `cells/_guard_*/`;
  - `cad_cache/`;
  - the six validator OUTPUT folders: `open3d_center_row_face_visual/`,
    `open3d_five_penta_initial_visual/`, `perf_ns_trace/`, `five_penta_prism_cascade/`,
    `recorded_bug_repros/synthetic/`, `recorded_bug_repros/penta_telescope_chain/`;
  - editor temp files.

  The 3 `__pycache__` folders in `attachment/` were deleted (53 `.pyc` files).
- **`KRAKENOS_CELLS_DIR`** relocates new stations; unset, nothing changes. The 0667 guard points it
  at a temp folder, so it writes nothing into `attachment/` at all.
  - Phase 500 passes, and its station was created in `/tmp/guard_0667_cells_*`.
  - `attachment/cells/` stayed untouched during the run, and phase 514 (the other caller) passes.
- **`test_fixtures/`**: 23 input fixtures (2.3 MB) in git, at the same paths as in `attachment/`:
  - 12 layout scenes: `om05a_folded.py` (used by 92 validators), the `machine_vision_*` scenes, the
    five-penta cascades, `Basler_Telecentric`, `MV-CS050...`;
  - the 8 `cells/solved/` station files;
  - 3 recorded bug states.

  `tools/validator_fixtures.py` has `--check`, `--restore` (never overwrites), `--update` and
  `--collect`. Both penta gates restore missing fixtures before they run. Tested: a deleted scene
  came back byte-identical.
