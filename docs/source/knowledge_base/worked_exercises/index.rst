Worked Exercise Solutions
=========================

This section contains seven book-specific collections of textbook-style
exercises, plus a contributor guide and a compact worked example.  The aim is
not only to obtain an answer, but to make each mathematical decision visible:
what is known, which equation applies, how it is rearranged, how units are
handled, and how the result is checked.

Start with :doc:`writing_a_solution` when adding an exercise.  The thin-lens
example introduces the solution format; book-specific collections have their
own parent pages.

.. note::

   Record the book title, edition, chapter, and exercise number, but write the
   problem in your own words unless the text permits reproduction.  A short
   paraphrase is enough to understand and solve the exercise.
