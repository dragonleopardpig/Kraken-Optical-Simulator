Photonics Essentials
====================

Worked solutions for Thomas P. Pearsall, *Photonics Essentials: An
Introduction with Experiments* (McGraw-Hill, 2003).

Each solution paraphrases the problem, states any data or material properties
that the question leaves implicit, and develops the result step by step.
Source errors are identified rather than carried into later calculations.
