Understanding Lasers
====================

Worked solutions for the chapter quizzes in Jeff Hecht,
*Understanding Lasers: An Entry-Level Guide*, fourth edition (Wiley/IEEE
Press, 2019).

Each page paraphrases the questions, gives a quick-answer table, and explains
the reasoning.  Numerical problems include the governing equation,
substitution, units, and a check where useful.  Notes identify cases where the
printed answer key conflicts with the question, the chapter text, or direct
calculation.
