Photonics Essentials: Worked Problems
=====================================

Worked solutions for Thomas P. Pearsall, *Photonics Essentials: An
Introduction with Experiments* (McGraw-Hill, 2003).

Each solution paraphrases the problem, states any data or material properties
that the question leaves implicit, and develops the result step by step.
Source errors are identified rather than carried into later calculations.
Problems that require laboratory measurements include a procedure, expected
trend, and results table instead of invented observations.

Each problem or review question initially shows a **Brief solution** with the
method, decisive step, and answer.  Use **Show detailed steps** to expand the
complete derivation, procedure, tables, figures, and verification.
