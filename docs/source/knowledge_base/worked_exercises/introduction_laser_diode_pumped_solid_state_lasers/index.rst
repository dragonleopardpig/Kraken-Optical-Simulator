Introduction to Laser Diode-Pumped Solid State Lasers
======================================================

This collection contains worked reading notes for Richard Scheps,
*Introduction to Laser Diode-Pumped Solid State Lasers* (SPIE Tutorial Texts,
2002).  It expands numerical statements that the book presents compactly,
defines the quantities used in each design argument, and checks implicit
assumptions where the printed estimate does not follow exactly from the stated
numbers.

The notes are organized by book chapter so that further questions can be added
in reading order.  They paraphrase the reference and provide independent
calculations rather than reproducing its text.
