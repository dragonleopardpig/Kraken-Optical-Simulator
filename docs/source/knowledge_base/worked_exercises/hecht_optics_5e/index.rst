Optics, Fifth Edition — Worked Exercise Solutions
==================================================

This collection accompanies Eugene Hecht, *Optics*, fifth Global Edition.
It covers every one of the 831 end-of-chapter problems in Chapters 2--13;
Chapter 1 is included in the navigation to record that the edition has no
end-of-chapter problem set there.

The short solutions expose the governing relation, the decisive algebra or
construction, and a verification step.  Problem statements are deliberately
not reproduced: use the exercise number with the book.  An asterisk preserves
the book's marker for one of the 558 problems omitted from its selected
answers.  For the other 273 problems, a compact result check is included when
the printed answer could be extracted reliably.
